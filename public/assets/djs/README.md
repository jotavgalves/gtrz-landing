# Assets dos DJs

Pasta preparada para imagens estáticas de fallback.

Caminhos recomendados:

- `/assets/djs/vogn.webp`
- `/assets/djs/glitzy.webp`

Você pode colocar JPG, PNG ou WebP aqui e informar o caminho no painel.

Em produção, o fluxo recomendado é usar o upload do painel com o binding R2 `MEDIA`; nesse caso as imagens ficam em `/media/djs/...` e não exigem commit/deploy.
